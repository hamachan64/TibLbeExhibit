# Treasure Haul キービジュアル

## 3D 版（作業中・2026-10-22）
ステージとお宝の実モデルを Blender（Cycles）で配置して描いた。**人物と会場は仮置き**（人物は実際の撮影写真、会場は会場の写真に差し替える予定）。

**狙い:** 「壊すな」の一番ヤバい瞬間。青がつまずいて黄金の日輪盤が手から飛び、欠けた破片が散る。緑が飛び込んで両手のビームで受け止め、奥で赤が叫んで指さし、黄が頭を抱える。低いカメラ・広角・傾けた画面で勢いを出し、右上の会場の冷たい光と左下の作業灯の暖色で二色に割る。（1 回目の「通路の奥に祭壇・全員が立っている」構図は、わかりやすいがワクワクしない、という判断で作り直した。Git の履歴に残っている）

### 構図とステージの関係
- 実際のステージは入口の正面に「中央の塊」（前と奥の部屋）がある。キービジュアルでは**中央の塊（外殻・仕切り・正面の祭壇・両部屋の家具とお宝）だけを非表示**にし、奥の横通路から大広間の入口の前を舞台にした。外周の壁・大広間の仕切り・祭壇・壁龕・家具はステージのとおり。
- 主役の日輪盤（`gilded_sun_disc`）は大広間の祭壇から持ち出された想定で、宙に浮かせた。祭壇の大釜は非表示。
- 床は全面を会場のカーペット（ステージは床を作らず、会場の床をパススルーで見せる設計に合わせた）。

### カメラ（Blender の座標。奥行は -Y）
- 位置 (-0.75, -6.4, 0.38)。(0.25, -10.4, 1.55) を見上げる（約 16°）。画面を 11° 傾ける。焦点距離 18mm（センサー幅 36mm、水平画角 約 90°）。

### 照明
- 右上の会場からの冷色のスポット（強い主光）、左下の床の作業灯からの暖色（下からの光）。日輪盤には反射用の暖色の光と小さな点光源。
- 奥の大広間の祭壇の真上からの暖色（赤と黄を逆光で浮かせる）。既存の作業灯・電球。薄い霧と、光の中に舞うほこり。
- 会場: 天井の冷色の面光源。**ライトリンクで会場の物だけを照らす**。
- 仕上げ（合成ノード `KV_Comp`）: 深度で奥の会場を少しかすませる、光のにじみ（Bloom）、周辺減光。色調は AgX - Punchy。

### 人物の撮影の目安（写真で差し替えるとき）
カメラ: **高さ 約 40cm、約 16° 見上げ、35mm 判で 18mm 相当**（撮った後で画面を 11° 傾ける）。人物の位置は「カメラの向きに前へ何 m、左右へ何 m」。全員ヘッドセット着用、コントローラーなし。驚き・焦りが伝わるように、**口を大きく開ける・体全体で動く**のが大事（目はヘッドセットで隠れるため）。

| 人 | 位置 | ポーズ | 主な光 |
| --- | --- | --- | --- |
| 緑 | 前へ 1.7m、右へ 1.6m | 左奥（日輪盤）へ向かって飛び込む。前の膝を曲げ、後ろ脚を伸ばし、両腕を前へ伸ばして手のひらを開く。上体は大きく前へ倒す | 右上から冷色、左下から暖色 |
| 青 | 前へ 2.9m、左へ 1.0m | つまずいて前のめり。片足が後ろに跳ね上がり、両手を上へ伸ばして飛んでいく日輪盤を追う。顔は日輪盤（右上）へ | 右上から冷色、下から暖色 |
| 赤 | 前へ 3.7m、右へ 0.7m | カメラの方を向いて叫ぶ。右腕で日輪盤を指さす | 後ろから暖色の逆光 |
| 黄 | 前へ 4.1m、左へ 0.3m | カメラの方を向いて両手で頭を抱える | 後ろから暖色の逆光 |

日輪盤は前へ 1.4m、左へ 0.4m、高さ 1.35m（3D で描くので撮影には要らない）。撮影は単色の背景か、同じ明るさの屋内で。実在の人物の写真は本人の同意があるものだけを使う。
