### 構図とステージの関係
- 実際のステージは入口の正面に「中央の塊」（前と奥の部屋）がある。キービジュアルでは**中央の塊（外殻・仕切り・正面の祭壇・両部屋の家具とお宝）だけを非表示**にし、入口から大広間の祭壇まで一直線に見通している。外周の壁・大広間の仕切り・祭壇・壁龕・家具はステージのとおり。
- 主役は大広間の祭壇の日輪盤（`gilded_sun_disc`、中央に寄せた）。祭壇の大釜は青の人が運ぶ壺に回した。緑の人がビームを当てているのは西の壁龕（置き場所 15）の黄金の仮面。
- 床は全面を会場のカーペットにした（ステージは床を作らず、会場の床をパススルーで見せる設計なので、それに合わせた）。

### カメラ（Blender の座標。奥行は -Y）
- 位置 (0, -2.0, 1.15)、ほぼ水平（1° 見上げ）、焦点距離 30mm（センサー幅 36mm、水平画角 約 62°）。

### 照明
- 遺跡: 既存の作業灯・電球＋祭壇の真上からの暖色スポット（天井のない遺跡に差す光）。日輪盤だけに当てる反射用の暖色の面光源。弱い霧。入口の 2 灯と中央の塊の作業灯は消した。
- 会場: 天井の冷色の面光源。**ライトリンクで会場の物だけを照らす**（遺跡を平板にしないため）。
- 人物: 祭壇側からの暖色の逆光、上からの冷色、正面からの弱い冷色（いずれも人物だけ）。
- 仕上げ（合成ノード `KV_Comp`）: 深度で奥の会場を少しかすませる、光のにじみ（Bloom）、周辺減光。

### 人物の撮影の目安（写真で差し替えるとき）
カメラ: 高さ 1.15m、水平、35mm 判で 30mm 相当。人物の位置は「カメラから前へ何 m、左右へ何 m」。主光は人物の**後ろ（奥）から**の暖色、正面は弱く。全員ヘッドセット着用、コントローラーなし。

| 人 | 位置 | ポーズ |
| --- | --- | --- |
| 黄 | 前へ 2.65m、左へ 1.2m | 背中向き。右手を高く上げて仲間に合図。顔は少し右へ |
| 赤 | 前へ 5.0m、左へ 0.7m | 背中向き（少し右へ回る）。右腕を伸ばして奥の祭壇を指さす |
| 青 | 前へ 3.8m、右へ 0.5m | カメラの方へ歩いてくる途中。壺（直径 約 40cm）を腰の高さで両手で持つ |
| 緑 | 前へ 3.95m、右へ 1.7m | 右の壁に向かってしゃがむ。左手を高さ 1m の壁龕へ向ける（手のひらを開く） |

背景の合成用に、撮影は単色の背景か、同じ明るさの屋内で。実在の人物の写真は本人の同意があるものだけを使う。

## 描いたこと
- **中央の主役**: 遺跡の奥の祭壇に置かれた黄金の円盤（ステージの大広間の祭壇と同じ構成）。作業灯と、天井のない遺跡に上から差す光で照らす。
- **現実の空間だとわかること**: 高さ 2.4m の壁の上に、**本物の展示会場**（屋根のトラス、吊り照明、隣のブースの看板、垂れ幕）が見える。手前の床は遺跡の石畳から会場のカーペットと黄色と黒の境界テープへ変わる。仮想の遺跡が現実の会場に重なっている MR であることを、説明なしで伝える。
- **4 人の体験者**（全員ヘッドセット、コントローラーなし）:
  - 手前左（黄）: 背中向きで手を高く上げ、仲間に「こっち！」と合図する
  - 中央左（赤）: 黄金の円盤を指さし、見つけたことを伝える
  - 中央右（青）: 青銅の壺を両手で抱えて運んでいる（M のお宝）
  - 右（緑）: しゃがんで壁龕の壺に手を向け、手のひらからの短いビームで光る輪郭を見つけた瞬間
  - 色の線は企画書の「1 人 1 色（赤・青・緑・黄）」に合わせた
- **避けたこと**: 一人称の画面、HUD、値札などの画面表示、過剰な発光、他作品の模倣。

## 余白
上部中央（会場の天井の部分）を明るさを抑えた余白にしてある。タイトルとキャッチコピーはここに置く想定（`keyvisual_layout_guide.png`）。右下はクレジット・ロゴ用。

## 作り直し方
```sh
cd Design/KeyVisual
python3 build_keyvisual.py                     # keyvisual.svg を作る
PLAYWRIGHT_MODULE=$(npm root -g)/playwright node render.mjs      # keyvisual.png
PLAYWRIGHT_MODULE=$(npm root -g)/playwright node render.mjs 2    # keyvisual@2x.png
PLAYWRIGHT_MODULE=$(npm root -g)/playwright node guide.mjs       # 余白の目安
```
カメラ（`CAM_Y`・`F`）、人物の位置（`P(x, 0, z)`）、色はスクリプトの先頭と各ブロックで変えられる。

## 限界
- 手描き相当のベクター（フラットな人物シルエットと逆光の縁取り）。商業ゲームの宣伝用の厚塗りイラストの水準ではない。
- 本番用に仕上げる場合は、この構図を下絵にしてイラストレーターに描いてもらうか、実際の体験者を会場（または似た空間）で撮影し、ステージの 3D を重ねて合成するのがよい（実写なら「現実の人がその世界にいる」がいっそう伝わる）。
