# Agent Memory (自動記憶)

このフォルダ（`.claude/agent-memory/`）は、Claude Code がセッション間で知識を永続化させるための記憶領域です。

## ルール
1. **発見と学習**: 既存の実装でハマったポイント、PICO APIのバグ回避策、STYLY NetSync特有の同期のコツなどを発見した場合は、自律的にこのフォルダ内の該当ファイル（例：`lbe-learnings.md`）に追記してください。
2. **作業前の確認**: 新しいセッションを開始し、LBE関連やマルチプレイ関連のタスクに着手する際は、必ず事前にこのフォルダの関連ドキュメントを読み込み、過去の学習内容を再確認してください。
