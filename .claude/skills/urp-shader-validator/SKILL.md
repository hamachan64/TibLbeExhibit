# URP シェーダーバリデーター

## 目的
モバイルVR（PICO / Meta Quest）環境において、60fps以上のパフォーマンスを維持しつつ、URP仕様に合致したシェーダー（「カード化」や「浮遊」エフェクトなど）を実装するための検証を行います。

## 指示内容
- シェーダーグラフや手書きのシェーダーコードが `Universal Render Pipeline` 互換であることを確認すること。
- VR特有の「Single Pass Instanced」レンダリングで正しく左右の目に描画されるかを検証すること。
- アルファブレンドの多用を避け、パフォーマンスへの影響が最小限になるようアドバイスすること。
- MR（パススルー）前提のため、CameraのBackgroundがSolid Color (Alpha=0) になっているか、またパススルー映像とブレンドされる際のアルファ表現が適正かを検証すること。
