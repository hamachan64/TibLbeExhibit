# Unity ログアナライザー

## 目的
ビルドエラーやランタイムエラーが発生した際に、不要なログ情報を省き、スタックトレースから根本原因を特定します。

## 指示内容
- 提供された `Editor.log` や Logcat の出力を読み込むこと。
- 非同期処理（UniTask）やリアクティブ（R3）における例外、またはOpenXR/PICO SDKに関連するネイティブクラッシュを重点的にチェックすること。
- エラーの原因だけでなく、具体的な修正コードの提案を含めること。
