# 展示デバイス（LBE）固有のルール

## 1. PICO Enterprise機能の制御
- 展示用途であるため、ユーザーが意図せずシステムメニューを開くことを防ぐなど、PICOエンタープライズ機能（`PXR_Enterprise`）を利用したデバイス制御が含まれます。
- `UserClient.cs` などのエントリーポイントで設定を行います。

## 2. プラットフォーム分岐の徹底
- PICO固有のAPIを呼び出す際は、Unity Editor上やMeta Quest（他のOpenXRデバイス）での実行時にコンパイルエラーやランタイムエラーが発生しないようにしてください。
- 適切なプリプロセッサディレクティブ（例: `#if UNITY_ANDROID` や固有のDefineシンボル）またはインターフェースを利用した抽象化を検討してください。
