# 減額と表示（3回で壊れる）

Issue: #39 ／ ブランチ: `repo/feature-damage`（`repo/develop` から作成）
設計書: `TREASURE_HAUL_DESIGN.md` 第8版 4.2・4.3・5章・6章（6.1・6.2）・8章（個人の記録の材料）・9章／要件定義書 第7版 F-DMG-1〜6
Issue の追記（設計書 第5版）: 減額の免除は判定役がホストへ伝え、ホストが**お宝ごとに**判断する（お宝同士では免除中の方だけ減額しない）。**再接触**（判定役がローカルで、接触が終わってから〔再減額の間隔〕0.5秒たった後の接触だけを報告）と、**通信上の重複**（ホストが、同じ組み合わせの報告を直前の報告から〔重複とみなす時間〕0.3秒以内なら捨てる）を分ける。`ThDamage` は送り直さない。

## 目的
本編中にお宝をぶつけると、ぶつけた回数で値段が下がる（元の値段の 30%・30%・40%、3回目で0になり砕けて消える）。
減ったことが全員に見えて聞こえ（「-90G」の赤い表示、段階的なヒビ、その場所から鳴る音）、初めてぶつけた人には「ぶつけると値段が下がる」が出る。
体験の核「高い宝を見つける → 慎重になる → ぶつける → 傷物でも回収する」の「ぶつける」が動くようになる。

## ユーザーと決めたこと（2026-10-19 の壁打ち）
- **まだ値段が公開されていない（値札が「？」の）お宝が減額されたときは、金額（「-30G」）を出さない**。値札は「？」のまま、ヒビと音だけ出す。減額はホストで数え、持った瞬間に下がった後の値段が出る（企画書 2章の4「いくらなのかは、持つまでわからない」を守る）。
  - 起きる場面: お宝同士は置いてあるお宝とぶつかっても両方を1回ずつ数える（U-15）ので、持っている・落としたお宝が未発見のお宝に当たると、未発見の方も減る。
  - オーケストレーターが企画書 5.3・要件 F-DMG-4・設計書 5章/9章をこの内容に更新する（実装エージェントは文書を触らない）。
- **減額の免除は「仕組み＋手元へ飛ぶ途中」まで**。判定役→ホストの免除の報告と、ホストのお宝ごとの判断（状態 Flying / Placing / Hovering と免除の報告）を作り、今ある「手元へ飛ぶ途中」に使う。手の飛び・補正の無判定時間・そっと置く・見失い待ちの**動き自体は #41** で作り、そのときに免除の報告を立てるだけで済むようにしておく。

## 受け入れ基準

### A. 減額の計算（純粋。F-DMG-1/5）
- [ ] 純粋クラス `DamageCalculator`（static でよい）: 元の値段・今の価値・これまでの回数・減額率3つ（`ThParams.treasure.damagePercent1〜3`）から、今回の減額の量・減額後の価値・回数・消滅かを出す
  - 減額の量 = `元の値段 × 減額率[回数] / 100`（整数。元の値段は 100G 刻みなので割り切れる）。今の価値より大きければ今の価値で止める
  - 3回目で価値を0にして消滅にする（減額率の合計が 100% でなくても、3回目は必ず0）
  - すでに3回（消滅）なら何もしない
  - 例: 300G → 1回目 -90G（210G）→ 2回目 -90G（120G）→ 3回目 -120G（0G・消滅）／100G → -30G（70G）→ -30G（40G）→ -40G（0G）

### B. 衝突を見つける（判定役の端末。F-DMG-1/2/6、設計書 5章）
- [ ] **報告するのは、自分が動かしているお宝だけ**: 自分の端末で物理が動いている（`Mine` で Held の追従中、または Falling）お宝の `OnCollisionEnter` から。置かれている・他の端末が動かしている・飛んでいる途中のお宝は kinematic なので自分からは報告しない（相手が動いていれば相手の端末が報告する）
- [ ] **衝撃の速さ**: お宝ごとに、`FixedUpdate` ごとの実際の移動（`Rigidbody.position` の差 / dt）を〔速さをならすフレーム数〕（`speedSmoothFrames`、3）だけ覚え、衝突したときはその平均の速度を使う（純粋なリングバッファ。例: `VelocityHistory`）
  - 相手が障害物（床・瓦礫など、お宝でない物）: 自分の平均の速度の大きさ
  - 相手がお宝: **相対速度**（自分の平均の速度 − 相手の速度）の大きさ。相手が自分の端末で動いているお宝なら相手の `VelocityHistory`、他の端末が動かしているお宝なら受け取った位置から求めた速度（`PoseInterpolator` に直近2点から速度を出すメソッドを足す）、置かれているお宝なら 0
  - 〔数える衝撃〕（`impactSpeed`、0.8m/s）未満なら報告しない
- [ ] **再接触**（純粋クラス。例: `ContactTracker`）: お宝ごとに、相手（相手がお宝ならそのお宝の番号、そうでなければ相手の `Collider` の InstanceID）単位で接触を数える
  - 接触している間（同じ相手の別のコライダーとの接触を含む）は、新しい `OnCollisionEnter` を報告しない（押し付け続けても1回だけ）
  - 同じ相手との接触が終わってから〔再減額の間隔〕（`redamageInterval`、0.5秒）たつまでの接触は報告しない
  - 別の相手は別に数える。お宝が回収・消滅・手から外れた（状態が変わった）ときと、回の終わりで消す
- [ ] **持っているお宝が障害物に押し付けられたときに `OnCollisionEnter` が出るか**を PlayMode で確かめる（追従は `SweepTest` で障害物の 2mm 手前で止めるので、接触が生まれない可能性がある）。出ない場合は、`Treasure.ClampBySweep` で障害物に向かう成分を切ったこと（当たった相手と、切る前の向かう速さ）を同じ `ContactTracker` に「接触の始まり」として入れ、切らなくなったら「接触の終わり」にする。どちらにしたかを報告する
- [ ] **`ThDamage`**（判定役→ホスト）: `a`（自分のお宝）、`b`（相手のお宝。障害物なら -1）、`pos`（当たった点。`VenueRoot` ローカル）、`speed`（ログ用）。**送り直さない**（設計書 6.2）。送るのは、自分が参加端末で Playing 中、結果に入る前（`Frozen` でない）だけ
- [ ] **免除の報告**（設計書 5章「位置の送信に載せる」）: `ThPoseEntry` に `exempt`（bool）を足す。判定役は、自分が動かしているお宝が免除中なら `true` を載せる。#39 では「手元へ飛ぶ途中」（`Treasure.IsFlying`）だけが免除。#41 が手の飛び・補正・そっと置く・見失い待ちを足すときに、ここを1か所変えれば済む形にする（例: `Treasure.IsDamageExempt` か、`ClientItem` の免除のプロパティ）

### C. ホストが数える（F-DMG-1〜3/5/6、設計書 5章・6.1）
- [ ] `HostItem` に `ExemptReported`（判定役から報告された免除）を足す。ホストは `ThPoses` を受け取り（今は捨てている）、**送り手がそのお宝の判定役で、お宝が消えていない**ときだけ `exempt` を覚える。`ThGrabbed`（持ち主が替わる）・`ThFreed`・回収・消滅で `false` に戻す
- [ ] ホストの「免除中」= `ExemptReported` か、状態が Flying / Placing / Hovering
- [ ] `HostItemTable.OnDamage(deviceId, ThDamageMsg, now)`:
  - 受け付け条件（6.1）: Playing 中（呼び出し側の今のゲートのまま）、送り手が `a` か `b` の少なくとも1つの**判定役**。満たさなければ捨てる（重複の記録もしない）

  - お宝ごとに**別々に**判断する: お宝が無い・消えている（回収・消滅）・練習用・免除中なら、そのお宝には適用しない（もう一方には適用する）

## 検証方法
- EditMode テスト: 上の F のとおり
- PlayMode / 目視: 上の F の「エディタでの確認」。スクリーンショット、ホスト・端末のログ

## 実機確認が必要な項目
- 本物の手で運んだとき、〔数える衝撃〕0.8m/s で「ぶつけた」と感じる強さと合っているか、そっと置いたつもりで減らないか（#49・#45）
- 手の認識のぶれで、押し付けている間に接触が切れて〔再減額の間隔〕の後に数え直されることがないか（#49）
- 4台で、お宝同士の衝突が両方の端末から報告されても1回にまとまるか（会場の Wi-Fi の遅れで〔重複とみなす時間〕0.3秒が足りるか。#45）
